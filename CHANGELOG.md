# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and new entries arrive as per-PR fragments in [`changelog.d/`](changelog.d/README.md), which a post-merge workflow collates under `## [Unreleased]` (do not edit this file by hand in a PR). The dated `## YYYY-MM` groups below it are the pre-versioning history; once the repository starts cutting tagged releases, each group can be moved under a `## [X.Y.Z]` heading (or merged into a single initial-version section) without rewriting any entry. Schema-level detail lives in the per-schema changelogs: [set](schemas/set/CHANGELOG.md), [manifest](schemas/manifest/CHANGELOG.md) and [checklist](schemas/checklist/CHANGELOG.md).
